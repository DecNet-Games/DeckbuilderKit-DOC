# The Game in the Box

This is a complete kit because a complete game ships inside it:

- **150+ cards** across archetypes — counted in the verification record, and every one of them played by the balance harness.
- **Three acts** of encounters — combat, elites, events, rest sites, shops — with a boss at each act's end, each act playable end-to-end.
- **A full loop to play on day one**: map → combat → rewards → events/shops/rest → boss → next act, with meta-progression carrying unlocks into your next run.

Content uses only package-included material — flat card art that is minimal, clearly labelled placeholder, and reskinnable. No external asset dependency, no missing-reference errors on import.

Play the game first. Then open its data files: every card you just played against is a file you can read, copy and change.
