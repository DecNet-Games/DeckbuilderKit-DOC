# Installation

The Single-Player Deckbuilder / Card Battler Complete Kit is a **commercial Unity Asset Store product**. Purchase and installation happen through the Asset Store — it is not available as a free download.

{: .important }
> Buyers install from the Unity Asset Store only.

---

## Requirements

- **Unity 2022.3 LTS or Unity 6 (6000.x).**
- Single-player only: no networking components, nothing to operate.
- The package ships with everything it needs: engines, content, presentation layer, tests and documentation. No external asset dependency.

## Steps

1. Purchase the package on the Unity Asset Store.
2. In Unity, open the Package Manager and import it from **My Assets**.
3. Open the sample game and play a run — the complete loop (map, combat, events, shop, boss) is the fastest tour of the kit.
4. Add your first card as a data file (see the [Quick Start]({{ site.baseurl }}/docs/quick-start/)).

## What is in the package

| Part | Contents |
|---|---|
| Card/effect engine | Data model + deterministic resolution engine, triggers, keywords/statuses |
| Run structure | 3-act map generation, encounters, meta/save |
| Enemy system | Intent-based behaviour, elites and bosses, data-driven patterns |
| Balance harness | Automated run-throughs, win-rate curves per act and archetype |
| Content | 150+ cards, 3 acts of encounters, events, shops, bosses |
| Presentation | Hand/combat interface, run map, deck viewer, event/shop/rest screens |
| Tests | The full test suite, with a README on how to run it |
