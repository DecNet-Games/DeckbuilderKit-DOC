# Frequently Asked Questions

**Is this a framework or a game?**
Both, deliberately: a complete playable game (150+ cards, three acts) whose machinery — card engine, run loop, intent system, harness — is the product you build on.

**Do I need to write code to add a card?**
No. Cards and enemies are data files. Malformed data is reported with an error naming the entry.

**Is there multiplayer or online play?**
No — single-player by deliberate scope. See [Limitations]({{ site.baseurl }}/docs/limitations/).

**How do I balance my own content?**
With the included harness: your cards and enemies join its pools automatically, and it reports win-rate curves per act and archetype.

**Can I reskin everything?**
Yes. Presentation is style-only; swapping art changes no engine behaviour.

**Where do I get support?**
support@decnetgames.com.
